# IntersectIA Mobile

## Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.
This project is **Expo SDK 57** (React Native 0.86, React 19.2, new architecture + Hermes always on).

## What this is

A thin Expo Router app that mirrors the IntersectIA landing and talks to the NestJS backend. It has
**no simulation logic**; the backend is the source of truth (`../intersectia-backend`).

Two tab routes:

- `src/app/index.tsx` — welcome/landing content, sourced from `src/constants/landing.ts`
  (port of `../intersectia-frontend/components/sections/*`). The frontend remains the canonical copy.
- `src/app/asistente.tsx` — chatbot UI. Uses `useChat` (`src/hooks/use-chat.ts`), backed by the
  portable `src/lib/chat/` client (`client.ts`, `session.ts`, `types.ts`) — same design as
  `intersectia-frontend/lib/chat`, so the two can be diffed side by side.

## Commands

- `npm start` — Metro; `npm run android` compiles + installs (`expo run:android`).
- `npm run typecheck` — `tsc --noEmit` (the reliable check).
- `npx expo-doctor` — project health.
- `npm run lint` — `expo lint`; scaffolds ESLint config on first run.
- Local Android build: `npm run prebuild:android` then `./gradlew assembleRelease` from `android/`.
  `android/` is gitignored and regenerated by prebuild.

## Environment

- `EXPO_PUBLIC_API_URL` (see `.env.example`), read as `API_URL` in `src/constants/config.ts`. The app
  POSTs to `${API_URL}/ai/chat` with `{ message, sessionId }` → `{ answer }`, and GETs
  `${API_URL}/ai/chat/topics` for the suggestion chips.
- Default when unset: Android `http://10.0.2.2:3000` (emulator → host), else `http://localhost:3000`.
- Cleartext HTTP is enabled in `app.json` via `expo-build-properties` for local dev; disable for
  production HTTPS.

## Conventions

- Path alias `@/*` → `src/*`; non-route code lives outside `src/app`.
- UI copy is Spanish, matching the landing. Keep it that way.
- Theming: `src/constants/theme.ts` mirrors the landing palette (dark default, accent `#f5a623`).
  Read colors with `useTheme()`; style with `StyleSheet` (no Tailwind here).
- No comments in source unless truly necessary.
- Chat session id is in-memory (`createMemoryStore` in `src/lib/chat/session.ts`); there is no
  persistent storage dependency. Swap the store for AsyncStorage later without touching the client.
